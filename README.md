# فوتبال‌نما — MVP و جمع‌آوری خبر

این پروژه یک سایت استاتیک فارسی به‌همراه عامل جمع‌آوری خبرهای فوتبال است. عامل ۱۹ منبع فعال را در سه گروه پوشش می‌دهد: رسانه‌های معتبر بین‌المللی، رسانه‌های محلی انگلیس، آلمان، اسپانیا، ایتالیا، فرانسه و هلند، و منابع تخصصی تحلیل داده، تاکتیک و استعدادیابی. لینک منبع در همه خبرها حفظ می‌شود.

## اجرای جمع‌آورنده

```bash
python3 scripts/sports_news_scraper.py --limit-per-source 8 --max-items 180
```

برای بازسازی کامل خروجی بدون ادغام آرشیو قبلی، گزینه `--fresh` را اضافه کنید.

پس از اجرا، فایل‌های `dist/data/news.js` و `dist/data/status.json` ساخته می‌شوند. خروجی اختصاصی عامل در `dist/news-agent.html` قرار دارد و جست‌وجو، فیلتر منبع و موضوع، وضعیت منابع و لینک مستقیم خبر اصلی را نمایش می‌دهد. آرشیو حداکثر ۲۰۰ خبر در `var/news_archive.json` نگه داشته می‌شود.

## ترجمه فارسی خودکار

کلید API را فقط به‌صورت متغیر محیطی تنظیم کنید و داخل فایل یا مخزن قرار ندهید:

```bash
export OPENAI_API_KEY="..."
python3 scripts/sports_news_scraper.py --translate
```

مدل پیش‌فرض `gpt-5.6-luna` است. برای تغییر آن از `OPENAI_TRANSLATION_MODEL` یا گزینه `--model` استفاده کنید. ترجمه‌ها کش می‌شوند تا یک خبر تکراری دوباره هزینه ایجاد نکند.

عنوان و خلاصه خبرهای ESPN مطابق شرایط ارائه‌دهنده بدون تغییر نمایش داده می‌شوند، صریحاً با نام ESPN مشخص می‌شوند و وارد مرحله ترجمه خودکار نمی‌شوند.

## افزودن منبع

یک رکورد تازه به `config/sources.json` اضافه کنید. فید باید RSS یا Atom معتبر داشته باشد. بهتر است پیش از افزودن یک سایت، شرایط استفاده و مجوز بازنشر آن بررسی شود؛ این پروژه فقط عنوان، خلاصه کوتاه و لینک منبع را نگه می‌دارد و متن کامل مقاله را کپی نمی‌کند.

## اجرای زمان‌بندی‌شده

برای محیط واقعی می‌توان همین دستور را هر ۱۰ تا ۱۵ دقیقه با cron، GitHub Actions یا سرویس زمان‌بندی سرور اجرا کرد. فایل خروجی باید همراه سایت منتشر شود.
