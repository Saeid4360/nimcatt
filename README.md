# فوتبال‌نما — MVP و جمع‌آوری خبر

این پروژه یک سایت استاتیک فارسی به‌همراه عامل جمع‌آوری خبرهای فوتبال است. عامل ۳۱ فید سراسری و ۲۰۰ کانال تیم‌محور را پوشش می‌دهد. کانال‌های تیم‌محور برای ۴۰ باشگاه پرطرفدار تعریف شده‌اند و رسانه رسمی باشگاه، رسانه محلی و منابع هواداری را از هم تفکیک می‌کنند. لینک منبع در همه خبرها حفظ می‌شود.

## اجرای جمع‌آورنده

```bash
python3 scripts/sports_news_scraper.py --limit-per-source 8 --team-limit-per-source 3 --max-items 280 --workers 10
```

برای بازسازی کامل خروجی بدون ادغام آرشیو قبلی، گزینه `--fresh` را اضافه کنید.

پس از اجرا، فایل‌های `dist/data/news.js` و `dist/data/status.json` ساخته می‌شوند. خروجی اختصاصی عامل در `dist/news-agent.html` قرار دارد و جست‌وجو، فیلتر تیم، نوع منبع و موضوع، وضعیت منابع و لینک مستقیم خبر اصلی را نمایش می‌دهد. آرشیو حداکثر ۲۸۰ خبر در `var/news_archive.json` نگه داشته می‌شود. نشانی فیدهای کشف‌شده در `var/team_feed_cache.json` کش می‌شود تا اجرای بعدی سریع‌تر باشد.

خبرهای فوتبال زنان در مرحله دریافت و هنگام ادغام آرشیو با فیلتر چندزبانه کنار گذاشته می‌شوند. برای پاک‌سازی آفلاین آرشیو موجود نیز می‌توان `python3 scripts/sports_news_scraper.py --prune-only` را اجرا کرد.

## ترجمه فارسی خودکار

کلید API را فقط به‌صورت متغیر محیطی تنظیم کنید و داخل فایل یا مخزن قرار ندهید:

```bash
export OPENAI_API_KEY="..."
python3 scripts/sports_news_scraper.py --translate
```

مدل پیش‌فرض `gpt-5.6-luna` است. برای تغییر آن از `OPENAI_TRANSLATION_MODEL` یا گزینه `--model` استفاده کنید. ترجمه‌ها کش می‌شوند تا یک خبر تکراری دوباره هزینه ایجاد نکند.

عنوان و خلاصه خبرهای ESPN مطابق شرایط ارائه‌دهنده بدون تغییر نمایش داده می‌شوند، صریحاً با نام ESPN مشخص می‌شوند و وارد مرحله ترجمه خودکار نمی‌شوند.

## افزودن منبع

برای منبع سراسری یک رکورد به `config/sources.json` اضافه کنید. فید باید RSS یا Atom معتبر داشته باشد. برای پوشش تیمی، باشگاه و پنج دامنه منتخب آن را در `config/team_source_catalog.json` ثبت کنید؛ عامل فید عمومی ناشر را به‌طور خودکار پیدا می‌کند. بهتر است پیش از افزودن سایت، شرایط استفاده و مجوز بازنشر آن بررسی شود؛ این پروژه فقط عنوان، خلاصه کوتاه و لینک منبع را نگه می‌دارد و متن کامل مقاله را کپی نمی‌کند.

## به‌روزرسانی خودکار روی سایت

نسخه میزبانی‌شده از مسیر `/api/news-feed` خبرها را از فیدهای فعال می‌خواند و خروجی را ۱۵ دقیقه در D1 نگه می‌دارد. با بازشدن خبرخوان، نسخه ذخیره‌شده فوراً نمایش داده می‌شود و اگر قدیمی باشد دریافت تازه در پس‌زمینه آغاز می‌شود. دکمه «دریافت خبرهای تازه» نیز به‌روزرسانی فوری را اجرا می‌کند. فیدها به‌صورت چرخشی خوانده می‌شوند تا منابع اصلی همیشه و منابع تیمی در چند چرخه متوالی پوشش داده شوند.

اسکریپت پایتون بالا همچنان برای بازسازی آفلاین آرشیو و تهیه خروجی اولیه قابل استفاده است.
